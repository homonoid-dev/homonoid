# Development Prompts

The `prompts` directory contains reusable prompts for AI-assisted development.

These prompts are designed to improve consistency across documentation, implementation, code reviews, and project maintenance. They should be implementation-independent and reusable across different AI systems and development environments.

Typical contents include:

```text
prompts/
├── component-specification.md
├── implementation.md
├── review.md
└── release.md
```

Prompts should describe objectives, expected outputs, constraints, and project-specific context rather than relying on assumptions about the repository.

<br>

### Engineering Principle

Reusable knowledge produces consistent results.

Prompts should capture repeatable development patterns that improve quality while reducing ambiguity.
