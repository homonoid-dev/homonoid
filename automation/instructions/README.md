# Development Instructions

The `instructions` directory contains implementation guidelines for specific areas of the Harmonia ecosystem.

These documents define engineering expectations, development standards, and implementation requirements. They complement the project documentation by describing how contributors should approach specific tasks while remaining consistent with the Harmonia design language.

Typical contents include:

```text
instructions/
├── component.md
├── documentation.md
├── icons.md
├── motion.md
└── tokens.md
```

Each document focuses on a single area of development and should provide practical guidance without duplicating the project's formal specifications.

<br>

### Engineering Principle

Consistency begins with shared practices.

Implementation instructions should establish clear expectations while allowing platform-specific solutions where appropriate.
