# Development Automation

The `automation` directory contains the knowledge, instructions, templates, and workflows used to develop the Harmonia ecosystem.

Its purpose is to provide both developers and AI-assisted development tools with a shared understanding of the project's architecture, philosophy, engineering standards, and development workflows.

The contents of this directory are implementation-independent and should be treated as supporting documentation rather than production code.

<br>

### Structure

```text
automation/
├── context/
├── instructions/
├── prompts/
├── workflows/
└── templates/
```

<br>

### context

Provides high-level knowledge about Harmonia, including its architecture, design philosophy, terminology, and project structure.

<br>

### instructions

Defines implementation standards and engineering guidelines for specific areas of the project.

<br>

### prompts

Reusable prompts for AI-assisted development tasks such as component generation, code reviews, documentation, and implementation guidance.

<br>

### workflows

Documents repeatable development processes including creating new components, publishing packages, and maintaining the project.

<br>

### templates

Reusable templates for specifications, documentation, packages, and other project artifacts.

<br>

### Engineering Principle

Knowledge should be reusable.

Whenever knowledge can be documented, standardized, or automated, it should be captured here to improve consistency, reduce repetition, and accelerate development.
