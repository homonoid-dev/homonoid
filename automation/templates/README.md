# Development Templates

The `templates` directory contains reusable document and project templates used throughout the Homonoid ecosystem.

Templates establish a consistent structure for specifications, documentation, packages, and other project artifacts while reducing repetitive work.

Typical contents include:

```text
templates/
├── component.md
├── package.md
└── specification.md
```

Templates should define structure rather than content. They provide a starting point that contributors can adapt while maintaining consistency across the project.

<br>

### Engineering Principle

Consistency is easier to achieve when every artifact begins from a common foundation.

Templates should minimize repetition while encouraging predictable project organization.
