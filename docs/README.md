# Harmonia Documentation

Harmonia is a cross platform design system built around continuity.

This documentation defines the philosophy, principles, and long-term direction of the Harmonia ecosystem. Rather than documenting individual implementations, these documents describe the ideas that every implementation must preserve.

<br>

### Contents
- Manifesto
- Philosophy
- Motion
- Roadmap

Every platform implementation is expected to follow these specifications while embracing the strengths of its native ecosystem.

The documentation in this directory is considered the source of truth for the Harmonia design language.
